# EmploymentHero recruitment candidate export


Tampermonkey userscript to a button to EmploymentHero's recruitment screen to be able to export applicants for a job as a csv list, eg for loading into other applications/workflows.

<img width="367" height="150" alt="image" src="https://github.com/user-attachments/assets/de2af842-a1b9-484a-b178-06adf695ed5a" />


1. Install [the Tampermonkey extension](https://www.tampermonkey.net/) in your browser
2. Install the userscript by clicking on the 'raw' button in GitHub or by clicking [this link](https://github.com/CanterburyMuseum/employmenthero-candidatelist-export-userscript/raw/refs/heads/main/employmenthero-tampermonkey.user.js)
